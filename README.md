# Souza Reis PDV Light

## About the Project

Souza Reis PDV Light is a lightweight point-of-sale (POS) system developed in partnership to help small business owners manage their daily sales, income, and expenses.

The project focuses on simplicity and practicality, providing essential financial tracking without the complexity of electronic tax invoice issuance or payment terminal integrations.

The planned architecture includes three applications:

- **Mobile:** React Native
- **Web Frontend:** React and Vite
- **Backend:** C# and .NET

The goal is to provide small businesses with a straightforward way to track money coming in and going out, helping them maintain better control over their daily operations.

## How to Run the Project

**Prerequisites:** Git, Node.js, npm, and the .NET SDK. Additional requirements may vary depending on the application being developed.

### 1. Clone the Repository

```bash
git clone https://github.com/alberyReis/souza_reis_pdv_light.git
```

### 2. Navigate to the Project Directory

```bash
cd souza_reis_pdv_light
```

### 3. Install Dependencies

Install the dependencies required by the application you want to run. For the web frontend, navigate to its directory and run:

```bash
npm install
```

### 4. Start the Application

For the web frontend, run:

```bash
npm run dev
```

For the backend and mobile applications, follow the setup instructions defined in their respective project directories.
